### This folder 

This folder contains data relevant to Section 5.3 of the paper:
- benchmarks: contains all instances used in the experimental evaluation
- results: contains the raw files with the outputs generated by the tool on a given command
- Jupyter: contains the Jupyter notebook used to produce the plots in the paper, which also contains additional statistics on the experiments. 

### The Jupyter notebook

To run the notebook, start by creating a Python virtual environment (if you don't have one already): 

`python -m venv /path/to/new/virtual/environment` 

Activate the environment: 

`source <venv>/bin/activate`

And install (`pip install`) the following dependencies `jupyterlab`, `matplotlib`, `numpy`, `pandas`, `typing`. 

Afterwards, navigate to the folder Jupyter contained contained in the same directory as this file, and start the notebook with `jupyter notebook`. Your browser will open a page, from which you can open the file `a-notebook.ipynb`. 

Once in the notebook, you can select `Run -> Run all cells` to compile all the data of the experimental evaluation. This will also regenerate the plots, a copy of which is already located in `Jupyter/plots`. The folder `Jupyter/CSV` contains all CSVs used in the notebook.
